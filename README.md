# DEEP STELLAR — Website Version 2

A cinematic, responsive space-exploration website built with **HTML, CSS and vanilla JavaScript**.

## Included features
- Premium dark space theme and animated logo treatment
- Responsive navigation and mobile menu
- Animated starfield background and scroll reveal effects
- Hero section with CSS astronaut/planet artwork
- Universe discovery cards
- Interactive 3D solar system powered by Three.js
- Planet selector and planet information panel
- Mission Control dashboard and fictional Stellar One mission timeline
- Documentary cards with category filters and live search
- Captain Alex crew profile
- Cosmic gallery
- YouTube calls to action

## Run locally
1. Extract the ZIP.
2. Open the `deep-stellar-v2` folder.
3. Double-click `index.html` to preview, or use VS Code with the Live Server extension.
4. Internet is required for Google Fonts, remote demo images and the Three.js CDN.

## Important customization
- Replace `https://www.youtube.com/@DeepStellar` in `index.html` with your actual channel URL if it differs.
- Replace the three sample documentary cards with your real video titles, thumbnails and YouTube links.
- Replace remote Unsplash images with your own licensed images when ready.
- Captain Alex and Stellar One are presented as fictional brand/story elements. Keep factual astronomy content scientifically accurate.
- The 3D solar system is a visual learning model, not to scale. Planet sizes, distances and orbital speeds are simplified for display.
- Contact/newsletter backend, analytics, user accounts and a content management system are not included; those require backend/API integration.
